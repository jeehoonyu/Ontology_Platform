# Docs-Grounded Validation Matrix

This matrix validates the local Ontology AIP Platform against public Foundry/AIP behavior and the local `foundry-docs` corpus. It is a behavioral conformance matrix, not a proprietary API or source-code comparison.

Status legend:

- `MATCH`: the local implementation supports the documented behavior directly.
- `LOCAL_ANALOG`: the local implementation provides the same architectural role with deterministic local substitutes.
- `PARTIAL`: the behavior exists but lacks documented depth or visual fidelity.
- `INTENTIONAL_DIFFERENCE`: the documented behavior depends on Palantir-managed infrastructure, private services, or proprietary UI internals and is represented locally by a bounded substitute.
- `MISSING`: no meaningful local behavior exists yet.

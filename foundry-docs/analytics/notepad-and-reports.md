# Notepad & Reports

> Notepad is Foundry's document and report builder for combining formatted text and media with live, embedded analytical and operational artifacts from across the platform.

## What it is

Notepad is where you tell the story behind the data. It's a rich document editor — like a word processor — but you can embed **live Foundry artifacts**: charts, tables, object references, Contour analyses, Quiver dashboards, images, and more. Because embeds stay connected to their sources, a Notepad report updates as the underlying data changes, making it ideal for recurring briefings, analyses, and operational reports that must stay current.

## When to use it

- Writing analytical reports, briefings, or documentation that include live data.
- Combining narrative text with charts, tables, and object references.
- Producing recurring reports that should refresh automatically.

**When NOT to use it / alternatives:** For interactive operational tools use **Workshop**; for spreadsheet modeling use **Fusion**; for pure tabular analysis use **Contour**.

## Key concepts & terminology

- **Notepad document** — The report/document you author.
- **Embed / widget** — A live, connected artifact (chart, table, object reference, analysis).
- **Template** — A reusable report structure.
- **Object reference** — Inline live reference to an Ontology object/property.
- **Section / formatting** — Rich text, headings, media, and layout.

## Core capabilities / features

- **Rich text + media** — Format documents with text, images, and structure.
- **Live embeds** — Insert charts, tables, object references, and other Foundry artifacts that stay connected.
- **Auto-updating reports** — Content reflects current data on open/refresh.
- **Object references** — Reference live object properties inline in prose.
- **Templates** — Standardize recurring reports.
- **Sharing & governance** — Documents respect Foundry permissions/markings.

## How it works / typical workflow

1. **Create a Notepad document** in a project.
2. **Write narrative** with rich text and headings.
3. **Embed live artifacts** — charts, tables, object references, analyses.
4. **Format and arrange** sections and media.
5. **Share** the report; recipients see current data.
6. **Reuse via templates** for recurring reporting.

## Example

A weekly operations brief: narrative summary at the top, an embedded **Contour** chart of throughput, a live **object table** of open incidents from the Ontology, and inline references to key KPI objects. Each Monday the same document reflects the latest numbers automatically.

## How it connects to the rest of Foundry

- **Contour / Quiver** — Analyses and charts embed as live artifacts.
- **Ontology** — Object references and tables stay connected to live data.
- **Workshop** — Operational apps complement static reports.
- **Security** — Embeds respect the viewer's permissions.

## Tips & gotchas for learners

- **Embeds stay live** — reports refresh with the data, unlike static documents.
- **Use templates** for recurring briefings to save time.
- **Permissions cascade** — viewers only see embedded data they're authorized for.
- **Notepad is for narrative + data**; for interactivity, link to a Workshop app.
